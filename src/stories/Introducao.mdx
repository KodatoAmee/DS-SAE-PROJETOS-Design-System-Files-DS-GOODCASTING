# DS-GoodCasting

Design system da **Good Casting**: plataforma que conecta talentos, produtoras, agências, marcas e diretores de casting. Estrutura herdada do DS-Zara; identidade do brandbook (logotipo, Azul Tiffany); tipo: Bodoni Moda + Public Sans.

> Good Casting. Uma plataforma. Mil oportunidades.

**Propósito.** Transformar a forma como o mercado de entretenimento descobre, conecta e valoriza talentos por meio da tecnologia.

**Posicionamento.** Plataforma tecnológica que conecta talento e indústria de forma simples, inteligente e transparente.

Missão e visão: brandbook, p. 5–6.

## Princípios (da personalidade da marca)

1. **Inovadora.** Buscamos novas formas de resolver o casting: fluxo mais curto antes de ornamento. Circuito e malha hexagonal são os únicos grafismos tecnológicos; use com parcimônia.
2. **Humana.** A tecnologia aproxima pessoas: linguagem clara, controles de 44px em toque, raios suaves.
3. **Confiável.** Transparência e profissionalismo: cachê, prazo, vagas e estado da candidatura sempre visíveis; nenhuma promessa de trabalho.
4. **Elegante.** Preto, branco e um só acento: Azul Tiffany. Simplicidade, clareza, atenção ao detalhe.
5. **Visionária.** Pensar no futuro do casting, não só no presente: cada decisão vale para web e app, tema claro e escuro.
6. **Inclusiva.** O talento não tem um único perfil: contraste AA nos tokens, teclado, leitor de tela e `prefers-reduced-motion` em todo componente; exemplos com perfis variados.

## Voz e texto

Vale para rótulos, mensagens, exemplos das stories e documentação.

1. **Não prometer trabalho, seleção, convite ou resultado.** A promessa é de processo: transparência, profissionalismo, inovação.
2. **Frases curtas, afirmativas, com ponto final.** Uma ideia por frase.
3. **A marca fala em "nós"; o usuário é "você".**
4. **Vocabulário fixo:** talentos, produtoras, agências, marcas, diretores de casting. "Oportunidade", nunca "vaga garantida".
5. **Sem superlativo nem exclamação.** Ênfase com negrito em uma palavra.
6. **Assinatura sempre inteira:** "Good Casting. Uma plataforma. Mil oportunidades."

## Uso

Requisitos: React 19 (`react` e `react-dom` `^19.0.0`) e, só se usar `theme.css`, Tailwind v4.

O pacote é privado (não está no npm). Instale direto do GitHub; ainda não há tags, então use `#main` até existir a tag da versão:

```powershell
npm install github:KodatoAmee/DS-SAE-PROJETOS-Design-System-Files-DS-GOODCASTING#<tag-ou-branch>
```

Na instalação, o npm roda o `prepare` do DS (`npm run build`), que gera `dist/lib`.

```tsx
import "ds-goodcasting/styles.css";          // sem Tailwind no app
import { Button, Logo } from "ds-goodcasting";

<Logo width={160} />
<Button variant="brand">Completar perfil</Button>
```

Com Tailwind v4 no app, use o `theme.css` no lugar do `styles.css` (ele já importa o `tailwindcss`) e aponte o `@source` para os componentes, com caminho relativo ao arquivo CSS:

```css
@import "ds-goodcasting/theme.css";
@source "../node_modules/ds-goodcasting/dist/lib";
```

O tema vai no `<html>`: `<html data-theme="light">` ou `<html data-theme="dark">`. Sem o atributo vale o claro. Um `data-theme` em outro elemento cria uma ilha de tema.

Regras de contribuição em `GOVERNANCA.md`; contrato para quem escreve componente em `CONTRATO.md`.
