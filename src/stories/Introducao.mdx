# DS-GoodCasting

Design system da **Good Casting**: plataforma que liga talentos, produtoras, agências, marcas e diretores de casting. Estrutura herdada do DS-Zara; identidade do brandbook (logótipo, Azul Tiffany, Playfair Display + Inter).

> Good Casting. Uma plataforma. Mil oportunidades.

## Princípios (da personalidade da marca)

1. **Elegante.** Preto, branco e um só acento: Azul Tiffany. Simplicidade, clareza, atenção ao detalhe.
2. **Confiável.** Contraste AA garantido nos tokens; o Tiffany nunca leva texto branco.
3. **Humana.** A tecnologia aproxima pessoas: linguagem clara, controles de 44px em toque, raios suaves.
4. **Inovadora.** O circuito do logótipo é o único ornamento tecnológico; use com parcimónia.
5. **Inclusiva.** Teclado, leitor de ecrã e `prefers-reduced-motion` em todo componente.

## Camadas

| Camada | Arquivo | Papel |
|---|---|---|
| Tokens | `tokens/tokens.json` | Fonte canônica (W3C DTCG) |
| Tema | `src/styles/theme.css` | Primitivas → semânticas por tema → `@theme` do Tailwind v4 |
| Utilitários | `src/lib/cn.ts` | `cn()` e `focusRing` |
| Componentes | `src/components/{brand,actions,form,nav,content}` | React 19 + `cva` |

## Uso

```tsx
import "ds-goodcasting/styles.css";          // sem Tailwind no app
import { Button, Logo } from "ds-goodcasting";

<div data-theme="light">
  <Logo width={160} />
  <Button variant="brand">Completar perfil</Button>
</div>
```

Com Tailwind v4 no app: importe `ds-goodcasting/theme.css` e adicione `@source "../node_modules/ds-goodcasting/dist/lib";`.
